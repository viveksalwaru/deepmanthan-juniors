➗ Quadratic Equations

A quadratic draws a parabola (U-shape). Where it touches the x-axis are the roots!

y = 1x2 + 0x - 4

🧠 The Big Idea

  • General form ax² + bx + c = 0. The graph is a parabola — opening up if a > 0, down if a < 0.
  • The discriminant D = b² − 4ac reveals the roots: D > 0 two real roots · D = 0 one repeated root · D < 0 no real roots.
  • Roots by formula: x = (−b ± √D) / 2a. The vertex is the turning point.
